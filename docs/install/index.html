Install Plugin Player (Windows beta)

One file, one double-click. About a minute.

What you need

  • Windows 10 or 11, 64-bit.
  • A graphics chip that does WebGL2 with float render targets: any NVIDIA, AMD or Intel GPU from the last several years. A laptop with a dedicated GPU (NVIDIA / AMD) is best for the fluid scenes.
  • 8 GB of RAM or more.
  • On the first run Plugin Player checks this computer once: graphics (WebGL2, float targets, not a software driver), RAM, and about 30 fps on the first scene. If something is short you'll see one line: "This computer's graphics may struggle with these scenes. Close other apps, try ⧉ OUTPUT › OUTPUT QUALITY 720p, or use a laptop with a dedicated GPU." Plugin Player still runs. Click × and it won't show again.
  • About 400 MB of free disk space.
  • No admin password. Plugin Player installs for your Windows user only.

1. Download

Download Plugin-Player-Setup-0.2.1.exe (about 140 MB) from getpluginplayer.com.

Your browser may say the file "isn't commonly downloaded". Choose Keep (in Edge: the … menu next to the download, then Keep, then Keep anyway).

2. Run it, and the blue Windows box

Double-click the file. Windows will probably show a blue box:

Windows protected your PC Microsoft Defender SmartScreen prevented an unrecognized app from starting.

That is normal for this beta. Here is why: apps carry a digital signature that tells Windows who made them. We haven't bought that signature yet, so Windows doesn't recognise Plugin Player and asks you to confirm. The file is the same one we tested.

  1. Click More info.
  2. Click Run anyway.

If there is no More info link: right-click the file, choose Properties, tick Unblock at the bottom, click OK, and double-click it again.

If it says "Smart App Control blocked an app"

Some Windows 11 PCs have Smart App Control turned on. It has no "run anyway" button. In our tests it let the installer and the installed player through, but it decides per PC and per version. If it blocks the installer or Plugin Player, tell us [beta contact]. You don't have to turn Smart App Control off. We would rather fix it our end (the signed build fixes it).

Antivirus, Bluetooth and camera privacy prompts, step by step: SECURITY_PROMPTS.md.

3. What happens next

There are no setup pages. The installer runs for a few seconds, then Plugin Player opens on its own, fullscreen. A first scene is already playing.

  • F11 = fullscreen on / off. Esc leaves fullscreen. Quit with the window's close button.
  • To open it again: Start menu → Plugin Player, or the Plugin Player icon on your desktop.
  • The first launch compiles the scenes, which takes up to ~20 s. Later launches are much faster.

Then go to FIRST_RUN.md §3 for the tour.

What's in the beta

  • Twelve scenes: Cube Bloom, Frame Stack, Goop (fluid dynamics), Plane Drift, Corridor Panels, Cube Stack, Custom Particles, Blob Tracking v3, Pixel Smear, Flashpoint, Machine Vision, Typewriter Terrain, with all their presets.
  • Webcam input. Plugin Player tries your camera at start. If another app is using it, ⧉ INPUT says BLOCKED, a SOMETHING BLOCKED? card shows how to fix it, and the scenes play on the demo clip, a short loop of someone waving at a webcam (CAMERA.md, SECURITY_PROMPTS.md).
  • The first launch compiles the scenes for your graphics card: the first scene plays after about 10 s, the heaviest (Custom Particles, Blob Tracking v3, Pixel Smear, Flashpoint) finish in the background within the first minute. Every launch after that is under a second.
  • 8BitDo Micro controller support, with automatic pairing (CONTROLLER.md).
  • Spout, built in, both ways (nothing extra to install): the SPOUT switch in the ⧉ OUTPUT box or --spout sends the picture to Resolume Arena as the Spout source Plugin Player; ⧉ INPUT › SPOUT takes Arena's composition in like a camera (OUTPUT.md §4).

Updates

You never reinstall by hand. New versions (fixes and new scenes) arrive by themselves:

  • While the app is open it checks for a new version now and then and downloads it quietly in the background. Nothing pops up, nothing restarts, the show keeps playing.
  • When it's ready, an UPDATE chip appears at the top right (UPDATE READY · RESTART on a very wide window). Click it to see what's new.
  • It installs by itself the next time you quit. Or click RESTART NOW when you're not on stage: the screen goes dark for a few seconds and the new version opens.
  • Your shows, projector mapping, presets and unlocks stay exactly as they were.
  • No internet? Nothing happens; it tries again later.
  • If that panel says VERSION … IS OUT and offers OPEN REXAFFECTS.COM, Windows didn't let the automatic install run on your computer (this can happen with the beta because it isn't signed yet). Download the new installer from rexaffects.com and run it over the old one: everything you saved stays.

Where it lives

WhatWhere
The appC:\Users\<you>\AppData\Local\Programs\rexaffects-player\
Your shows, your projector mapping, the scene cacheC:\Users\<you>\AppData\Roaming\rexaffects-player\

Uninstall

Settings → Apps → Installed apps → Plugin Player 0.2.1 → … → Uninstall. (Or Control Panel → Programs and Features.) There are no questions and it takes a few seconds.

The uninstaller removes the app and its shortcuts. It keeps your shows and mapping (AppData\Roaming\rexaffects-player), so a reinstall picks up where you left off. To remove those too, delete that folder by hand after uninstalling.
