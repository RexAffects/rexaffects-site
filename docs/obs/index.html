Use Plugin Player in OBS

Put a Plugin Player scene (Flashpoint's Fire Feedback, say) into an OBS stream or recording.

The short version: on Windows, send it over Spout and add a Spout2 Capture source in OBS (one free plugin). On a Mac, send it over Syphon and add OBS's built-in Syphon Client source. No plugin? Window Capture works on Windows too.

Plugin Player has no NDI output. If OBS is on another computer, bring Plugin Player into OBS on this computer first, then send it on from OBS (for example with the free DistroAV plugin).

Before you start

  • Fire Feedback needs something moving. Flashpoint's fire comes off motion in the picture: your camera, a video file or the demo clip. On Windows only one app can use a camera at a time, so let Plugin Player have the webcam and don't add the same webcam in OBS. You're already in the picture Plugin Player sends.
  • A scene you haven't bought goes out with the RexAffects watermark at 720p detail, over Spout, Syphon and a full-screen window alike. Once you own it, it's clean 1080p. Cube Bloom is free. See UNLOCK.md.
  • Just recording, not streaming? OBS records too (Start Recording). A record button inside Plugin Player is coming in a later update.

Windows: Spout (recommended)

Spout hands OBS the picture straight from the graphics card: full quality, no app buttons, nothing to crop.

  1. Close OBS. Download the OBS Spout2 Plugin installer (OBS_Spout2_Plugin_Install_v…exe) from its releases page: https://github.com/Off-World-Live/obs-spout2-plugin/releases. Run it and keep the suggested folder. It needs OBS 33 or newer (on OBS 32, use plugin version 1.13.0).
  2. In Plugin Player, click ⧉ OUTPUT. At the bottom of the box, SPOUT OUT · SEND TO RESOLUME works for OBS too: turn it to SPOUT ON. It says WAITING FOR AN APP until OBS picks it up.
  3. Open OBS. In Sources, click + › Spout2 Capture, name it, click OK.
  4. In its settings, pick Plugin Player from the list of senders. If there's a composite mode setting, Opaque or Default is right (Plugin Player sends a solid picture). Click OK.
  5. The scene shows up in OBS. Plugin Player's box now says SENDING AS "Plugin Player".
  6. If it doesn't fill the OBS canvas: right-click the source › Transform › Fit to screen.

Spout carries only the picture: never the app's buttons, panels or the controller plate. Plugin Player can stay in a normal window with all its buttons while you play.

Windows: Window Capture (nothing to install)

  1. In Plugin Player, press G: the buttons and panels disappear and the picture fills the window. Make the window 16:9 (or press F11 for fullscreen) so there are no black bars.
  2. In OBS: Sources › + › Window Capture › OK.
  3. Window: pick the Plugin Player window. Capture Method: the Windows 10 (1903 and up) one (leave Automatic if that works). Click OK.
  4. Right-click the source › Transform › Fit to screen. Crop any edge with Alt + drag on the source.

Use Window Capture, not Game Capture. Press G again to get the buttons back after the stream. Spout is still the better picture: Window Capture copies what's on your screen, so it's capped at your window's size.

Mac: Syphon

Syphon is built into Plugin Player and into OBS: nothing to install. Plugin Player needs macOS 13 (Ventura) or newer.

  1. Update OBS to the newest version (older 32.0 builds could show a Syphon source blank; fixed in 32.0.2).
  2. In Plugin Player, click ⧉ OUTPUT and turn the switch at the bottom of the box to SYPHON ON.
  3. In OBS: Sources › + › Syphon Client, name it, OK.
  4. Source: pick the one that says Plugin Player. Leave Allow Transparency off. Click OK.
  5. Right-click the source › Transform › Fit to screen if it doesn't fill the canvas.

A clean picture that matches OBS

  • Size. Plugin Player sends 1920×1080 (or 1280×720 with ⧉ OUTPUT › OUTPUT QUALITY › 720p). Set OBS's Settings › Video › Base (Canvas) Resolution to the same. Streaming at 720p? Pick 720p in both: lighter on the graphics card than shrinking 1080p.
  • Frame rate. Set ⧉ OUTPUT › MAX FRAME RATE to the same number as OBS's Settings › Video › Common FPS Values (30 or 60; never above 60 over Spout). 30 is plenty for slow fire and halves the work.
  • No buttons in the picture. Spout and Syphon never carry them. With Window Capture, press G first.
  • Map in one place. Spout and Syphon send the picture before Plugin Player's MAP-tab mapping, so a projector mapping never ends up in your stream.

Transparent background? Not yet

Plugin Player always sends a solid picture: the black around the fire is real black, not see-through. To lay the fire over a camera or a game in OBS, put the Plugin Player source on top, right-click it › Blending Mode › Screen (or Additive). Black drops out and the bright fire stays.

Laptops with two graphics chips

Spout only works when Plugin Player and OBS run on the same graphics chip. On a laptop with an NVIDIA or AMD card plus the built-in one: Windows Settings › System › Display › Graphics › add Plugin Player and OBS › set both to High performance › restart both apps. Plugin Player shows this tip itself the first time you turn Spout on (HOW opens the steps). Full row: TROUBLESHOOTING.md › Laptop: Spout says ON, but Resolume (or OBS) shows black.

What you seeFix
Spout2 Capture isn't in OBS's + listClose OBS and run the plugin installer again. Check your OBS version (Help › About): plugin 1.14 and up need OBS 33; another plugin can clash with it (the plugin's page lists one). OBS must use its default Direct3D 11 renderer (Settings › Advanced).
The source is blackTwo graphics chips: see above. Check Plugin Player's box says SPOUT ON and the source has Plugin Player picked.
Plugin Player isn't in the sender listTurn SPOUT ON first, then open the source's settings again.
The picture is upside downStart Plugin Player with --spout-invert (OUTPUT.md › Where to type flags).
The fire doesn't moveFlashpoint needs motion: turn the camera on in Plugin Player (V), or play a video file. Close the webcam in OBS so Plugin Player can have it.
