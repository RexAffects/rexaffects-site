Troubleshooting — symptom → cause → fix

Where the log is: Plugin Player prints it to the terminal it was started from, as lines beginning [renderer], [player], [spout], [shows]. Start it from a terminal when you need them. A log file on disk [to confirm at beta]. The HUD (H) shows the live state on screen: fps, render size, GPU name, gamepads seen.

If it crashes

SymptomCauseFix
The app closed by itself, or the window went black or white for a momentA part of the app stopped (the graphics driver, a window's renderer) or Windows ended itStart it again. The next launch shows a small card, "Plugin Player closed unexpectedly last time. Send the log to RexAffects so it gets fixed?": press SEND, add a line about what you were doing if you like, press SEND again. That is the fastest way to get it fixed
A one-line note at the top: Something hiccupped · SEND LOGSomething stopped and the app recovered by itself (the picture came back)Carry on with your show. When you have a moment, press SEND LOG (or later: FEEDBACK / REQUEST → Bug)
What does SEND actually send?The crash summary (time, which part stopped, the exit code), the last lines of the log and, if Include support info is ticked, the app version, Windows, graphics card and controller. SHOW EXACTLY WHAT IS SENT shows every character first. Licence keys, emails, your Windows user name and full Bluetooth addresses are removed before anything leaves. Nothing is sent unless you press SEND
I don't want to be askedNOT NOW skips this one; DON'T ASK AGAIN turns the card off on this computer. You can still send a report any time from FEEDBACK / REQUEST
The card did not show after a crashIt waits until the loading screen and the first-run tips are done, and never shows in GUEST MODE (it waits for the next launch)Nothing to do, or send FEEDBACK / REQUEST → Bug yourself

When you report a problem

Include these four lines and your AI assistant, or we, can read it straight off: (Easiest: the FEEDBACK / REQUEST button at the bottom of the window, type Bug, with Include support info on. It carries all of the below.)

  1. The gl: line from the log (GPU name, WebGL2 or 1, float yes/no).
  2. The gamepad connected: line, or PAD NONE.
  3. Any SHADER INVALID, precompile … FAILED or [spout] line.
  4. The scene name and what you pressed.
