Midi Fighter Twister — the 16-knob button layouts

A DJ TechTools Midi Fighter Twister (16 push encoders in a 4×4 grid, 6 side buttons) drives Plugin Player out of the box with one of two button layout files in the installer/presets folder of the player (ask for them if you did not get them with your copy): Midi Fighter Twister.ppcontrols (· Dials) and Midi Fighter Twister - Pad layout.ppcontrols (· Pad layout, below). It is made for the Twister's factory MIDI map, bank 1 (the bank the Twister starts in): no change to the controller is needed. General MIDI set-up and the learn flow: MIDI_OSC.md.

Import the layout (once)

  1. Plug the Twister in. Open CONTROLS (F3). In the MIDI · OSC card click MIDI: OFF so it says ON — Midi Fighter Twister appears under it (a dot blinks when you turn a knob).
  2. Click IMPORT (next to SAVE LAYOUT / EXPORT), pick Midi Fighter Twister.ppcontrols, read the WHAT CHANGES list, click APPLY + KEEP AS LAYOUT. The LAYOUT dropdown now says MIDI FIGHTER TWISTER · DIALS (or · PAD LAYOUT). You can import both and switch in that dropdown.
    • It is a whole button layout: it also puts every scene's pad buttons back to their defaults and replaces any MIDI / OSC learns you had. If you want to keep yours, EXPORT first; UNDO in the toast puts everything back.
  3. Turn knob 1: the LIGHT value in the PRESETS monitor moves. Done.

Which layout to use

  • · Pad layout — you already play Plugin Player on a game controller (8BitDo, PlayStation, Xbox): the Twister is laid out like the pad, so the same move lives in the same place. Row 1 = □ △ ○ ✕, row 2 = d-pad + shoulders, row 3 = the sticks, row 4 = show tools. Push 1 does exactly what □ does in every scene.
  • · Dials — you want as many of each scene's dials as possible under your hands (12 per scene) and preset / scene buttons on the top rows. The grid is under Bank 1 — Dials below.

Both use bank 1 of the factory map and both make the rings follow.

Pixel Smear: a preset sets most of its dials, so its knobs are the ones that still move the picture on top of any preset (the melt masters, the motion field, exposure). It has no △ move, so push 11 is its MELT SURGE (the pad's L1: tap = lock, hold = boost).

Blob Melt: its fluid colours belong to the preset (and ○ deals a whole new fluid look from its own table), so its knobs are the boxes and stamps, plus the melt energy, which rides on top of every preset and every dealt look. Pushes 1-4 = □ stamp style · △ scoop ↔ live window · ○ deal · ✕ wipe.

A knob covers the dial's whole range: fully left = the minimum, fully right = the maximum (your range brackets on the PARAMS shelf narrow it). Custom Particles has no X action, so push 11 does nothing there.

The rings follow Plugin Player

Plugin Player sends each knob's value back to the Twister, so the LED ring of every knob shows where its dial is right now — whatever moved it: the knob, the pad's ▲ ▼, an OSC message, a preset change, a scene change, a glide. Change scene and all 16 rings jump to the new scene's values; change preset and they jump to the preset's values. Because the Twister's encoders take the value they are sent, the next click of a knob continues from the dial's real value — no jump after a scene or preset change.

  • It is the SEND VALUES BACK (RINGS / MOTOR FADERS) button next to Midi Fighter Twister in the MIDI · OSC card (CONTROLS tab). It is ON by itself for a Twister (and for any device that turns the layout's knobs); click it to stop sending. Other controllers stay OFF until you turn it on for them.
  • Only the knobs are sent (CC 0 … 15 on channel 1, plain MIDI CC, never SysEx); the ring colours stay the Twister's own. While you turn a knob, Plugin Player sends nothing to that knob (the ring already shows your hand).
  • If Resolume or another app has the Twister open, Windows may not let two apps use it at once — the same as for MIDI in.

Side buttons (if you set them to CC Hold in the Midi Fighter Utility; from the factory they switch banks and send nothing): left column top → bottom AUDIO ON / OFF · LEARN BACKGROUND · SCENE ↔ FX CHANNEL; right column FX PRESET 1 · FX PRESET 2 · FX PRESET 3.

GUEST MODE does not lock the Twister: every knob and push above keeps working for whoever holds it; only the CONTROLS tab (importing, learning, MIDI ON / OFF) is locked.

Your Twister set to RELATIVE (endless) encoders?

The layout expects the factory absolute encoders (0 … 127, the ring shows the position). If you set the encoders to a relative mode in the Midi Fighter Utility (ENC 3FH/41H), the knobs will jump instead of turn: on the CONTROLS tab click a knob's chip (for example CC 4 · CH1) and under KNOB pick RELATIVE (BIN. OFFSET) (3FH/41H = 63 / 65 = binary offset). Do it once per knob you use; it is saved with the layout. CHANNEL and DEVICE can stay on ANY.

The 5-minute test

  1. Plug in, MIDI ON, import the layout (above). The MIDI chip in the header says MIDI 1.
  2. Turn knob 1 → the LIGHT value in the PRESETS monitor follows (1× at about the middle, 2.5× fully right). Turn knob 5 → the scene speeds up / slows down. Knobs 9 … 16 → the scene's dials (watch the PARAMS shelf).
  3. Push knob 1 → next favourite preset (toast PRESET 2/12 · …). Push 2 → the previous one. Push 5 → next scene; push 7 → back to where you were.
  4. Push 9 → the scene's ○ button (Cube Bloom: a random look). Hold it: it is held like the pad's button.
  5. Unplug the USB cable while holding push 9, then plug it back in: nothing stays held, the MIDI chip goes OFF → MIDI 1 again, the knobs work at once.
  6. GUEST MODE on (Plugin Player ▾ → GUEST MODE…): knobs and pushes still work; the CONTROLS tab says locked.
  7. The rings: press L2 (next scene) or R2 (next preset) on the pad → all 16 rings jump to the new values. Click the LIGHT ▲ in the PRESETS monitor → ring 1 moves up a notch.
  8. MONITOR ▾ on the CONTROLS tab: each message shows what it did (CC 4 · CH1 → SLIDER animRate, CC 0 · CH2 → NEXT FAVOURITE PRESET). A line that says NOT BOUND is a control the layout does not map (bank 2 … 4, or a side button).

Hand test on your own Twister (5 minutes, both layouts)

What was already proved on a real Twister without touching it (Oct 30, Seat 3): Windows shows Midi Fighter Twister as an input AND an output, Plugin Player opens both, imports either layout with 0 warnings, and sends the 16 ring values on channel 1 (CC 0–15) on import, on every scene change and while a dial moves. What only your hands can prove is the knobs and pushes coming in. Start in Cube Bloom, with the Twister on bank 1 (the factory bank; the LEDs of the side buttons show the bank) and nothing else using it (if Resolume has the Twister ticked in Preferences › MIDI, untick it or quit Resolume first).

A · Dials layout (Midi Fighter Twister.ppcontrols)

  1. CONTROLS (F3) › MIDI · OSC › MIDI: ON; Midi Fighter Twister is listed and SEND VALUES BACK says ON. IMPORT the file › APPLY + KEEP AS LAYOUT. All 16 rings jump to a position at once (that is Plugin Player talking to the Twister).
  2. Turn knob 1 (top-left) → LIGHT in the PRESETS monitor follows (≈1× in the middle, 2.5× fully right). Put it back near the middle.
  3. Turn knob 5 (row 2, left) → Cube Bloom speeds up (right) / slows down (left). Knob 6 → the cube edges glow more / less.
  4. Push knob 1 → next preset (toast PRESET n/…) and the rings jump to the new preset. Push 2 → the previous preset.
  5. Push knob 9 (row 3, left) → a random look (Cube Bloom's ○). Push 5 → next scene (Frame Stack): every ring jumps again. Push 7 → back to Cube Bloom.
  6. Open MONITOR ▾: turning knob 5 shows CC 4 · CH1 → SLIDER animRate; pushing 1 shows CC 0 · CH2 → NEXT FAVOURITE PRESET. A side button shows NOT BOUND unless you set it to CC Hold (expected).

B · Pad layout (Midi Fighter Twister - Pad layout.ppcontrols, import it too and pick it in the LAYOUT dropdown)

  1. Push knob 3 (top row, ○) → a random look, exactly like ○ on the pad. Push knob 4 (✕) → the cubes spin.
  2. Push knob 1 (□) → spin: each cube ↔ whole block. Hold push 5 (L1) → the faces cycle as when you hold L1.
  3. Turn knob 5 → speed (the ▲▼ param); turn knob 6 → glow (the ◀▶ param); knob 7 → LIGHT.
  4. Push knob 7 (L2) → next scene: all 16 rings jump; push 13 → the previous scene.
  5. Push knob 10 → the FX layer comes on; push it again → off.

Pass = every step did what it says and no knob did two things. If a knob does nothing: MONITOR ▾ shows the message — a CH1 number other than CC 0 … 15 means the Twister is on another bank (press the side buttons back to bank 1) or was re-programmed in the Midi Fighter Utility (Reset to factory there, or learn that knob); nothing at all in MONITOR means another app has the port. If the knobs jump instead of turning smoothly, see RELATIVE above.

Known gaps

  • The rings follow the values (above), but their colours are not set by Plugin Player (no RGB / animation messages yet).
  • No 14-bit (high-resolution) encoder mode; banks 2 … 4 (CC 16 … 63) are not mapped — learn them on any row yourself.
  • The side buttons are mapped only if they send CC (see above).
